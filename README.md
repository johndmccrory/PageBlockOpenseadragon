# PageBlockOpenseadragon (module for Omeka-S)

This module provides an Openseadragon page block for Omeka-S.

This is a fork of the [PageBlockIframe](https://github.com/GhentCDH/Omeka-S-module-PageBlockIframe) module by the [GhentCDH](https://github.com/GhentCDH), adapted to embed OpenSeadragon viewers into Omeka S pages.

## Requirements

- Omeka-S >=4.0.0
